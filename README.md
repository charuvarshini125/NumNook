🧮 NumNook – Aesthetic Calculator

NumNook is a soft, minimal, blue-themed calculator designed with a cute and calming UI.
It combines clean design with smooth interactions, making everyday calculations feel aesthetic and effortless.

This project is built as a personal UI + web development project to showcase design sense and front-end fundamentals.

✨ Features
🎨 Design

Soft pastel blue aesthetic

Rounded buttons with gentle shadows

Minimal, modern calculator layout

Clean typography and spacing

Calm UI inspired by cozy desktop tools

🔢 Functionality

Basic arithmetic operations:

Addition (+)

Subtraction (−)

Multiplication (×)

Division (÷)

Real-time input display

Clear (C) and reset functionality

Error-safe calculations

🖱 Interaction

Click-based button input

Smooth hover and press effects

Responsive layout for different screen sizes
